# How To Run

## Step 1

Create Firebase project.

## Step 2

Enable:

* Authentication
* Email/Password Login
* Firestore Database

## Step 3

Replace Firebase keys in:

```javascript
js/firebase-config.js
```

## Step 4

Upload project to GitHub.

## Step 5

Enable GitHub Pages.
